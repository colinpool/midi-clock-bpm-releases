# MIDI Clock BPM releases

Downloads of MIDI Clock BPM, a free macOS app that shows the tempo, transport and bar count of incoming MIDI clock, from any MIDI input or a DAW.

Get the latest version at https://solutions.wire-online.com/products/midiclockbpm or under [Releases](https://github.com/colinpool/midi-clock-bpm-releases/releases).
